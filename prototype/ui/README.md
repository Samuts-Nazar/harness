# Прототип екрана гравця (UI)

Статичний фронтенд без бекенда й без запитів до моделей. Усі дані фейкові й сценарні (`data.js`).
Відкрити: `prototype/ui/index.html` у браузері (бажано у вікні ~390x844 або в режимі телефона).

- `index.html`, `style.css`, `app.js` (логіка), `data.js` (сцена: Рагнар у корчмі, Горст і Ельза).
- URL-параметр `?pace=0.2` прискорює стрімінг (множник затримок). Також є перемикач «Темп» у debug-панелі.
- Тест: `nix-shell prototype/ui/shell.nix --run "python prototype/ui/test_ui.py"` (Playwright, 390x844, скріншоти в `screenshots/`).

Припущення (рішення з `decisions.md`, що лишаються відкритими, зроблено найпростішими заглушками):
- Режим часу покроковий (світ чекає на гравця). Потоковий режим не реалізовано.
- Жодних кубиків, статів чи правил успіху. Чипи панелі це теги відкритих записів, а не схема.
- Вигляд екрана, швидкі реакції та натискні сутності це прототипи для оцінки на практиці.
