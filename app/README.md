# Застосунок для гри (телефон і ноутбук)

Мінімальний ігровий екран на справжньому рушії (`harness/`): корчма «Вовче Гніздо», ти Рагнар, поруч староста Горст і вдова Ельза. Пишеш дію чи слова, оповідь і репліки NPC йдуть слово за словом, кнопка «Перебити» зупиняє мовця.

## Запуск

З кореня репозиторію:

```
nix develop --command python -m app            # офлайн: сценарний фейк, без мережі й грошей
nix develop --command python -m app --live     # реальні дешеві моделі (OpenRouter, платно)
```

Відкрити на ноутбуці: http://127.0.0.1:8765/

Прапорці: `--port 8765`, `--pace 0.25` (секунд на слово), `--budget 1.0` (ліміт USD для `--live`), `--host`.

`--live` бере `OPENROUTER_API_KEY` з `.env` (ключ ніде не виводиться). Поки в `harness/policy.py` старий список дозволених моделей (до злиття задачі 9), додайте нові моделі в дозвіл:

```
HARNESS_EXTRA_ALLOWED=openai/gpt-6-luna,deepseek/deepseek-v4.1-flash-1017 \
  nix develop --command python -m app --live
```

## Телефон

1. Телефон і ноутбук в одній Wi-Fi мережі.
2. Запустити з `--host 0.0.0.0`:
   `nix develop --command python -m app --host 0.0.0.0` (додайте `--live` для реальних моделей).
3. Дізнатися IP ноутбука: `hostname -I` (перша адреса виду 192.168.x.x).
4. На телефоні відкрити `http://<IP-ноутбука>:8765/`.
5. Брандмауер: має бути відкритий **TCP-порт 8765** для локальної мережі. Скрипт нічого не змінює в системі й `/etc/nixos` не чіпає; порт відкриває власник (на NixOS це `networking.firewall.allowedTCPPorts = [ 8765 ];`).
6. Автентифікації немає: будь-хто в мережі, хто дістанеться порту, зможе грати й бачити debug. Не відкривати порт у чужих мережах.

Фонова вкладка: поки застосунок на телефоні згорнутий, слова не доставляються (світ чекає). Після повернення потік продовжується з того місця, де зупинився.

## Як грати

- Поле внизу: що робить і каже Рагнар, «Надіслати» (або Enter; Shift+Enter новий рядок).
- Поки текст іде, замість поля кнопка «Перебити». Натиснули під час репліки: решту NPC не сказав (вона лишається його невисловленим наміром у рушії). Під час оповіді кнопка зупиняє лише показ оповіді.
- Кнопка «Рагнар»: панель персонажа. Чипи: що з тобою зараз (заповнена крапка видно іншим, порожня знаєш лише ти), нижче кілька речень про те, що Рагнар знає. Там же «Почати гру спочатку».
- Кнопка Debug: останній хід. Час до першого слова і весь хід, виклики моделей (модель, секунди, вартість), судження, журнал подій, нотатки рушія (відхилені репліки тощо).
- Помилка моделі: червоне повідомлення над полем, ваш текст повертається в поле, світ не змінюється; можна надіслати ще раз.

## Що де

- `app/__main__.py` запуск; `server.py` HTTP + потік SSE; `game.py` сесія (потік ходу, події, пауза у фоні); `campaigns.py` створення кампанії (єдине місце, куди підключити збереження з диска); `stacks.py` фейк і live-моделі; `static/` сторінка.
- Події потоку: `turn_start`, `narr_start/narr_word/narr_end`, `speaker`, `word`, `turn_done`, `error`.
- Стан кампанії живе в пам'яті сервера: перезавантаження сторінки або перехід телефон/ноутбук його зберігає, перезапуск сервера починає нову гру (до підключення збережених кампаній).
